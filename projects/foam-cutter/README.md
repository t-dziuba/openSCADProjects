# Foam Cutter project

This is my small foam cutter project. I'm using it to cut small, advanced shapes for dioramas.

The polystyrene cutter was made of wooden boards (base), to which mechanical elements made of aluminum flat bar and handles enabling adjustment of the tilt angle are screwed. An additional handle printed on a 3D printer allows the resistance wire to be moved along the flat bar. This allows for setting angles in 2 XY planes.

The second part of the project is a simple electronic system for controlling the voltage and thus the temperature of the resistance wire.
